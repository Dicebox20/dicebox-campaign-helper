# Changelog

All notable changes to Regionwright are recorded here.

## Unreleased

### Regionwright: Puzzles & Traps

- Added the usable Free **Reveal a Secret** Studio template for hidden creatures and Tiles.
- Added visual hidden-Tile selection, locator feedback, reveal, and reset support.

### Regionwright: Studio

- Added pre-publish diagnostics for stale map references, target-type mismatches, incomplete objectives, and portal Scene errors.
- Routed Story Fact and Hub Unlock player triggers to the active GM so players never update world data directly.

## 0.1.1

### Regionwright: Puzzles & Traps

- Added the visual Regionwright launchpad and guided setup flow.
- Added map locator beacons for selected Regions, Doors, Tiles, and Actors.
- Added Tumbler Lock and Pitfall Trap guided setup.
- Added the publishable Pressure Plate Alarm Studio activity.
- Added clear cross-Scene setup guidance.
- Added GM-routed Door updates so players can complete supported locks without Door-edit permission.
- Prevented W, A, S, and D from moving a player's Token while a Regionwright lock puzzle is open.

### Regionwright: Studio

- Added Rotation Lock, a pick-and-turn Door puzzle.
- Added the Regionwright Studio foundation for visual scenario workflows.

## Release notes

- Regionwright supports Foundry VTT v14.
- Regionwright: Puzzles & Traps and Regionwright: Studio are replacement installations. Install one edition at a time.
