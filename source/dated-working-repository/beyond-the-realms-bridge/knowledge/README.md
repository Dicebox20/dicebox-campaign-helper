# BTR Bridge Knowledge Base

Read these files progressively. The source handoffs in `../reference/` remain
the provenance-bearing records; these files are compact navigation and
reconciliation surfaces.

1. `CURRENT_STATE.md`
2. `STATUS_MODEL.md`
3. `WORKFLOW.md`
4. `RUNTIME_RESULTS.md`
5. `FAILURES_AND_LESSONS.md`
6. `CANONICAL_SOURCES.md`

When a new BTR result is added, preserve the source date, evidence label,
runtime target, exact artifact identity, and whether the result is a fresh
observation or a carried-forward handoff claim.
