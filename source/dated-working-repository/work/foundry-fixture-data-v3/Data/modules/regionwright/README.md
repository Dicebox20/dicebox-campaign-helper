# Regionwright: Studio

Regionwright: Studio contains every feature in Regionwright: Puzzles & Traps plus the full Regionwright Studio workspace and premium puzzle library.

## Studio includes

- Everything in Regionwright: Puzzles & Traps.
- Regionwright Studio for connected, visual scenario design.
- Visual flow editing, conditions, counters, resettable state, cross-Scene checks, playtesting, and run records.
- Studio puzzle content, beginning with Rotation Lock.

## Installation

Regionwright: Studio replaces Regionwright: Puzzles & Traps in the `regionwright` module folder. Install only one edition at a time. Existing Regionwright settings and configured content stay in the same module namespace.

The release folder also includes the full Regionwright README with installation, support, and compatibility information.
