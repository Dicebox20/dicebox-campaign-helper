# Cabin in the Ashen Veil - Recovery Bundle

This campaign-only archive preserves the recovered material from the ChatGPT conversation **Halloween Campaign Idea**. It contains the reconstructed chat transcript, raw overlapping browser text capture, structured metadata, current handoff, recovered Library files and source handoff ZIP, artwork, map-planning files, and available 3D prototype assets including `build.py`.

## Contents and completeness

The recovered payload is stored as individual files in this directory. The generated enclosing `Cabin_in_the_Ashen_Veil_Recovery_Package.zip` is not stored here because it exceeds GitHub's 100 MiB single-file limit; its payload is represented by the individual files in this folder. The source Library handoff ZIP remains included.

The user-uploaded `index.html` 3x3 sliding-picture puzzle sample was visible in the source chat and Library but could not be downloaded. It is recorded as unavailable and is not represented as recovered.

Start with:

1. `campaign-handoff.md` - current design summary, dependencies, conflicts, and open work.
2. `campaign-chat-transcript.md` - reconstructed conversation, oldest to newest.
3. `campaign-metadata.json` - structured campaign and capture details.
4. `artifact-inventory.md` - recovered file paths, sizes, and SHA-256 hashes.

This is an archive for handoff and continuity. It is not integrated into the DiceBox Campaign Helper application or its knowledge base, and it does not claim Foundry runtime verification or production readiness.
