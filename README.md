# Dicebox Campaign Helper migration archive

This private repository preserves the 2026-10-01 migration from Dicebox Campaign Helper to its canonical successor, Dicebox Injector.

The `main` branch is the migration snapshot. The `historical-working-main` branch preserves the original committed Campaign Helper history.

Start with `DICEBOX_CAMPAIGN_HELPER_HANDOFF.md` once the migration documents are committed.
