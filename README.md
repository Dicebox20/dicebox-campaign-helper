# Dicebox Campaign Helper migration archive

This private repository preserves the 2026-10-01 migration from **Dicebox Campaign Helper** to its canonical successor, **Dicebox Injector**.

## Start here

- `DICEBOX_CAMPAIGN_HELPER_HANDOFF.md` — master manifest, provenance, classifications, unresolved work, integration guidance, and transfer checklist.
- `CAMPAIGN_KNOWLEDGE_TRANSFER.md` — campaign continuity and GM/mechanical state recoverable from this project.
- `CAMPAIGN_HELPER_WORKFLOWS.md` — reusable Campaign Helper procedures for reconciliation into Dicebox Injector.
- `metadata/MIGRATION_FILE_INVENTORY.csv` — complete transferred-source inventory.
- `metadata/CAMPAIGN_FACTS.csv`, `CAMPAIGN_DECISIONS.csv`, `OPEN_ITEMS.csv`, and `KB_SOURCES.csv` — structured knowledge exports.

## Branches

- `main` — complete migration snapshot, including the preserved dirty working-tree state.
- `historical-working-main` — original committed Campaign Helper Git history.

Campaign Helper policy is historical migration input. Newer Dicebox Injector standards take precedence.
